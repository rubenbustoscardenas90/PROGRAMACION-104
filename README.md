## Descripción del Proyecto
Aplicación desarrollada en Python bajo el paradigma de Programación Orientada a Objetos (POO), diseñada para gestionar clientes, servicios (alquiler de equipos, reserva de salas y asesorías especializadas) y reservas sin el uso de bases de datos. El sistema incorpora un manejo robusto de excepciones (personalizadas, bloques try/except/else/finally y encadenamiento), validaciones estrictas mediante propiedades y un registro automatizado de eventos y errores en archivos de logs.
